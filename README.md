# NEXUS AMMAN

**Smart City Emergency Coordination Platform** — *One City. One Connected Response.*

A conceptual university prototype of a unified emergency-coordination dashboard for the city of Amman, Jordan.

> **All data is fictional.** Incidents, teams, resources, statistics and charts are demonstration data only. The prototype has no connection to any real emergency service, police, hospital or government system. The map is a schematic illustration inspired by Amman's geography and is not geographically accurate.

## Pages

Overview, Live Incidents, Response Teams, Resources, City Intelligence and Analytics. It includes a stylized Amman map with clickable incident markers, search and filters, incident detail panels, and a working local "Create Demo Incident" form.

## Run it

Open `index.html` in a browser. It is a single self-contained page and needs no backend or build step. It loads React and htm from public CDNs, so an internet connection is required.

## Structure

- `index.html` — the complete prototype (this is the file to open or host).
- `src/` — the source parts it was assembled from: `p1-head.html` (styles), `p2-data.js` (data and icons), `p3-ui.js`, `p4-shell.js` and `p5-pages.js` (components, shell and pages).
